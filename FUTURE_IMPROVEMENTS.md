# Отложенный этап: дизайн, usability и CAPTCHA

Сохранено по указанию пользователя 15.09.2026. Это план, не разрешение автоматически
выполнять его. Текущий этап ограничен техническими пунктами review до раздела
«Дизайн и usability». Возвращаться к этому файлу при следующем запросе пользователя.

## Дизайн и usability

Сохранить зелёную палитру, антиквенные заголовки и крупные фотографии работ.

1. Первый экран: убрать исчезающий на светлом фоне градиент заголовка;
   сделать заголовок тёмным и стабильным. Сократить описание, основной текст
   набрать обычным шрифтом, курсив использовать как акцент.
2. Главная CTA — «Обсудить заказ» со ссылкой на контактную форму;
   вторичная — «Смотреть работы». Сейчас акцент на портфолио/бесплатных моделях.
3. Предложенный текст: «Медали, монеты и барельефы на заказ»;
   «Разрабатываю художественные 3D-модели с учётом чеканки и 3D-печати».
4. Контактные формы: ошибки полей на about, связанные label/id,
   сохранение ввода, переход к форме после ответа, понятное подтверждение.
   Футер сейчас отправляет на главную; унифицировать поведение.
5. Checkout цифровых товаров: не требовать город/страну без необходимости,
   объяснить способ получения файлов. Адрес запрашивать для физической доставки.
6. Уменьшенные превью WebP/AVIF, responsive images. Локально были картинки
   около 1,9–2,7 МБ. Убрать runtime Tailwind CDN в пользу готового локального CSS.
7. Проверить мобильные размеры, клавиатуру, фокус модальных окон,
   читаемость и reduced-motion. Предыдущий визуальный review охватил только
   локальный desktop; внешний сайт тогда не загрузился из браузера агента.

## CAPTCHA

Внедрить без переделки Django. Предпочтительный кандидат — Yandex SmartCaptcha
для основной аудитории в России, после проверки доступности на её устройствах.
Альтернатива — Cloudflare Turnstile, не требует переноса DNS/CDN.

Условия на дату review (перепроверить перед внедрением):
- SmartCaptcha: первые 10 000 проверок в месяц бесплатно, затем тарификация.
- Turnstile: бесплатный план с неограниченными проверками.
- Honeypot — дополнительная бесплатная защита; он уже реализован техническим этапом.

План интеграции:
1. Создать CAPTCHA для домена, публичный ключ в контексте, секрет только в `.env`.
2. Общий виджет для главной, about и футера; скрипт подключать один раз,
   экземпляры виджетов и токены держать раздельными для каждой формы.
3. Проверка токена сервером **до** записи ContactSubmission и SMTP.
   SmartCaptcha: POST `https://smartcaptcha.cloud.yandex.ru/validate`.
   Turnstile: POST `https://challenges.cloudflare.com/turnstile/v0/siteverify`.
4. Проверять ответ, домен и action там, где провайдер это поддерживает;
   не принимать пустой, просроченный или повторный токен.
5. Тайм-аут внешней проверки; при сбое сохранить текст, предложить повторить
   проверку/отправку, оставить email как альтернативу. Не принимать POST без
   проверки автоматически при недоступности провайдера.
6. Обновление токена при истечении и после невалидной формы; работа RU/EN.
7. Тесты: успешный токен, отсутствующий/неверный/повторный/просроченный токен,
   неверный hostname/action, сетевой сбой, все точки отправки, сохранение ввода.

Оценка из review: половина–один рабочий день на подключение с тестами;
стоимость сервиса может быть нулевой в рамках бесплатных условий.
CAPTCHA дополняет общие лимиты; не заменяет авторизацию и защиту от DDoS.
